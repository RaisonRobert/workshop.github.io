O que é o Firebase AI com Gemini?

É a forma oficial de colocar IA generativa dentro de um app Android: o SDK do Firebase AI Logic conecta seu código Kotlin direto aos modelos Gemini — sem backend próprio e sem expor chave de API.

📱 Seu app (Kotlin)→ Firebase AI Logic SDK→ ☁️ Gemini API→ Resposta no app

Como o seu app vai ficar

Esta é uma simulação ao vivo do app que você vai montar com as próprias mãos hoje: veja a pergunta sendo digitada, o botão disparando e o Gemini "digitando" a resposta (streaming). É exatamente esta tela que você vai construir na página de Implementação.

Mão na massa: código, agentes e prompts

Copie os trechos na ordem, rode a cada passo e finalize com o desafio. É aqui que o objetivo do workshop se cumpre: o Gemini respondendo na tela do seu app.

Monte o app completo (passo a passo, com MVVM)

Você vai montar esta tela: uma área de resposta em cima, um campo para digitar a pergunta e um botão para iniciar. Tudo em Jetpack Compose, com arquitetura MVVM em apenas 2 arquivos — e com o streaming já aplicado (efeito "digitando"). É a mesma tela da animação que você viu na Introdução. Os arquivos abaixo são reais, testados e prontos: se você criou o projeto com o package br.com.workshop.gemini (página de Configuração), cola tudo SEM mudar uma linha sequer. 💪

🖼️ View (tela Compose): só desenha→ 🧠 ViewModel: pensa e guarda o estado→ ☁️ Model (Gemini)

Por que MVVM? A tela (View) só exibe o que o ViewModel manda; toda a lógica fica no ViewModel. Sua resposta sobrevive à rotação de tela, o código fica organizado e fácil de testar — a mesma arquitetura usada em apps reais, como o Samsung Wallet.

Passo 1 · Crie o projeto com nome e package exatos

No Android Studio: File → New → New Project → Empty Activity (o template de Compose). Preencha EXATAMENTE assim: Name: WorkshopGemini · Package name: br.com.workshop.gemini · Minimum SDK: 24. Usar esses valores exatos é o que permite colar todos os arquivos sem editar nada. Depois, complete toda a página de Configuração — incluindo habilitar o AI Logic (Gemini Developer API) no console do Firebase e registrar o app com esse mesmo package.

⚠️ Não pule isso: sem o AI Logic habilitado no console do Firebase, o app compila e abre normalmente — mas toda pergunta devolve erro 403 / permission denied. Se isso acontecer, volte à página de Configuração (passo 2) e habilite a Gemini Developer API.

Passo 2 · Crie o arquivo GeminiViewModel.kt (o cérebro 🧠)

Clique com o botão direito na pasta br.com.workshop.gemini (onde está o MainActivity.kt) → New → Kotlin Class/File → dê o nome GeminiViewModel. Selecione tudo e cole o arquivo abaixo, exatamente como está:

GeminiViewModel.kt — arquivo completo (cole sem mudar nada)
package br.com.workshop.gemini

import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.setValue
import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.google.firebase.Firebase
import com.google.firebase.ai.ai
import com.google.firebase.ai.type.GenerativeBackend
import com.google.firebase.ai.type.content
import kotlinx.coroutines.launch

// ============== AGENTES PRONTOS (escolha um lá embaixo) ==============
const val AGENTE_ASSISTENTE =
    "Você é um assistente amigável. Responda sempre em português do Brasil, em até 3 frases."

const val AGENTE_PROFESSOR =
    "Você é um professor de Android. Explique como se fosse para um iniciante, com exemplos curtos em Kotlin."

const val AGENTE_VENDEDOR =
    "Você escreve descrições de produto para e-commerce: máximo 60 palavras, 1 parágrafo, destacando o principal benefício."

const val AGENTE_POETA =
    "Você responde qualquer pergunta em forma de poema curto de 4 versos, em português."

// ============== CONFIGURAÇÃO: mexa SÓ nestas 2 linhas ==============
const val MODELO = "gemini-3.8-flash"       // modelo do Gemini
const val AGENTE = AGENTE_PROFESSOR        // 👈 troque por qualquer agente acima, ou escreva o seu
// ====================================================================

class GeminiViewModel : ViewModel() {

    // O Model: o Gemini, já com a "personalidade" (AGENTE)
    private val model = Firebase.ai(backend = GenerativeBackend.googleAI()).generativeModel(
        modelName = MODELO,
        systemInstruction = content { text(AGENTE) }
    )

    // O ESTADO: a tela só lê; quem escreve é o ViewModel (private set)
    var resposta by mutableStateOf("A resposta do Gemini vai aparecer aqui. 👋")
        private set
    var carregando by mutableStateOf(false)
        private set

    // A AÇÃO: chamada pelo botão da tela
    fun perguntar(pergunta: String) {
        viewModelScope.launch {
            carregando = true
            resposta = ""
            try {
                // ⭐ STREAMING — a resposta chega aos poucos (efeito "digitando")
                model.generateContentStream(pergunta).collect { pedaco ->
                    resposta += pedaco.text ?: ""
                }
            } catch (e: Exception) {
                resposta = "Erro: ${e.message}"
            }
            carregando = false
        }
    }
}

Abra o MainActivity.kt, selecione tudo (Ctrl+A) e cole o arquivo abaixo. Repare como a View fica limpa: ela desenha, lê o estado do ViewModel e avisa o clique. Nada mais.

MainActivity.kt — arquivo completo (cole sem mudar nada)
package br.com.workshop.gemini

import android.os.Bundle
import androidx.activity.ComponentActivity
import androidx.activity.compose.setContent
import androidx.compose.foundation.layout.*
import androidx.compose.foundation.rememberScrollState
import androidx.compose.foundation.verticalScroll
import androidx.compose.material3.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import androidx.lifecycle.viewmodel.compose.viewModel

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent { MaterialTheme { TelaGemini() } }
    }
}

@Composable
fun TelaGemini(vm: GeminiViewModel = viewModel()) {
    // Só o texto sendo digitado fica na tela; o resto vive no ViewModel
    var pergunta by remember { mutableStateOf("") }

    Column(
        modifier = Modifier.fillMaxSize().padding(20.dp),
        verticalArrangement = Arrangement.spacedBy(16.dp)
    ) {
        // 1) ÁREA DA RESPOSTA (em cima) — exibe o estado do ViewModel
        Card(modifier = Modifier.weight(1f).fillMaxWidth()) {
            Column(Modifier.padding(16.dp).verticalScroll(rememberScrollState())) {
                if (vm.carregando && vm.resposta.isEmpty()) CircularProgressIndicator()
                else Text(vm.resposta)
            }
        }

        // 2) CAMPO PARA DIGITAR
        OutlinedTextField(
            value = pergunta,
            onValueChange = { pergunta = it },
            label = { Text("Digite sua pergunta") },
            modifier = Modifier.fillMaxWidth()
        )

        // 3) BOTÃO PARA INICIAR — só avisa o ViewModel
        Button(
            onClick = { vm.perguntar(pergunta) },
            enabled = pergunta.isNotBlank() && !vm.carregando,
            modifier = Modifier.fillMaxWidth()
        ) {
            Text(if (vm.carregando) "Pensando…" else "Perguntar ao Gemini")
        }
    }
}

Agentes: o Gemini chamando suas funções

Um agente decide quando chamar funções do seu app (function calling) para buscar dados reais. O fluxo é um loop:

Usuário pergunta→ Gemini decide chamar função→ Seu app executa (API, banco…)→ Gemini responde com o dado real

1 · Declare a ferramenta (função)

Agente.kt — declaração
import com.google.firebase.ai.type.FunctionDeclaration
import com.google.firebase.ai.type.Schema
import com.google.firebase.ai.type.Tool

// Descreva a função para o modelo: nome, o que faz e parâmetros
val buscarPreco = FunctionDeclaration(
    name = "buscarPreco",
    description = "Busca o preço atual de um produto no catálogo da loja",
    parameters = mapOf(
        "nomeProduto" to Schema.string("Nome do produto a buscar")
    )
)

// Crie o modelo com a ferramenta registrada
val model = Firebase.ai(backend = GenerativeBackend.googleAI()).generativeModel(
    modelName = "gemini-3.8-flash",
    tools = listOf(Tool.functionDeclarations(listOf(buscarPreco)))
)

2 · Rode o loop do agente

Agente.kt — loop
import com.google.firebase.ai.type.FunctionResponsePart
import com.google.firebase.ai.type.content
import kotlinx.serialization.json.*

lifecycleScope.launch {
    try {
        val chat = model.startChat()
        var resposta = chat.sendMessage("Quanto custa o Galaxy S25?")

        // Enquanto o modelo pedir funções, execute-as e devolva o resultado
        while (resposta.functionCalls.isNotEmpty()) {
            val partes = resposta.functionCalls.map { call ->
                // Leitura SEGURA do argumento (nada de !!, que derruba o app)
                val nome = (call.args["nomeProduto"] as? JsonPrimitive)?.content.orEmpty()

                // 👉 aqui entra a SUA lógica real: Room, Retrofit, Firestore…
                val preco = catalogoRepository.buscarPreco(nome)

                FunctionResponsePart(
                    call.name,
                    JsonObject(mapOf("preco" to JsonPrimitive(preco))),
                    call.id  // vincula a resposta à chamada certa
                )
            }
            resposta = chat.sendMessage(content("function") { partes.forEach { part(it) } })
        }

        println(resposta.text)  // "O Galaxy S25 custa R$ 5.299,00"
    } catch (e: Exception) {
        println("Erro no agente: ${e.message}")
    }
}
